## 退款政策里的四个坑，下单前必须知道

RackNerd 没有标准的退款保证（money-back guarantee）。它服务条款的原文是：退款按个案处理，付款到账后默认不退款。没有 7 天、14 天的无理由窗口，也没有按比例退还。这是整套购买决策里最需要提前消化的一条，下面四个具体的坑都和它有关。

**坑一：拒付会倒贴钱。** 对退款不满意直接找信用卡公司发起 chargeback，RackNerd 会收取 $125–$250 的行政费，账户还可能被暂停。真有计费问题，正确做法是开 Billing 工单说明情况，礼貌沟通下计费错误或开通异常是有机会处理的。

**坑二：取消不等于退款。** 在客户区点 Request Cancellation 只是停止未来续费，已付的费用不会回退。

**坑三：立即取消会在 24 小时内删光数据。** 选 Immediate Cancellation，系统 24 小时内终止服务并抹除全部数据，不可恢复。误点了要马上开工单申请重新激活，超时就真没了。

**坑四：想停掉续费要提前打招呼。** 续费取消需要在续费日前提前 5 天提交书面通知，合同类服务要提前 7 天。忘了这茬，账单照出。

应对方式也简单：用月付试水（1 GB 月付 $17.99），跑两周确认线路和稳定性满意，再转年付。年付金额本身不大，$21.99 即使真不合适，损失也有限——但 chargeback 这条路千万别走。
